# EPI Lab Open Source

**EPI Electronics Laboratory | Xi'an University of Posts and Telecommunications (XUPT)**

**西安邮电大学 EPI 电子实验室开源项目仓库**

## About Us | 关于我们

EPI Lab is an electronics innovation laboratory at Xi'an University of Posts and Telecommunications (XUPT), focusing on electronic system design, embedded development, hardware engineering, and technological innovation.

This repository is established to share technical achievements, engineering projects, and development resources, promoting knowledge sharing and open-source collaboration.

EPI 实验室致力于电子系统设计、嵌入式开发、硬件工程实践及技术创新。

本仓库用于集中管理和分享实验室的技术成果、工程项目及相关开发资源，促进技术交流、知识共享与开源协作。

## Project Areas | 项目方向

- **Hardware Design** — 电路设计、PCB 设计及硬件开发
- **Embedded Systems** — 单片机开发、嵌入式软硬件设计
- **Signal Processing** — 信号采集、分析与处理
- **Intelligent Systems** — 智能控制、人工智能及相关应用
- **Electronic Innovation** — 电子设计竞赛及创新实践项目

## Resources | 开源资源

本仓库根据项目实际情况提供以下资源：

- 硬件原理图与 PCB 设计文件
- 嘉立创 EDA 专业版工程文件（`.epro`）
- 嵌入式程序及相关源代码
- 项目技术文档与使用说明
- 测试资料及项目展示内容

部分大型工程文件通过 GitHub Releases 发布。
